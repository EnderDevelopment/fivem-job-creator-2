# FiveM Job Creator

The FiveM Job Creator is a resource designed to simplify the process of creating and managing jobs within the FiveM roleplaying environment. This tool allows server administrators to easily add new jobs with customizable names, descriptions, and salaries, enhancing the roleplay experience for players. The resource is built with Lua and is compatible with the FiveM platform, ensuring seamless integration with existing server setups.

## Install

1. Download the FiveM Job Creator resource from the GitHub repository.
2. Extract the downloaded files into your FiveM server's `resources` directory.
3. Add the following line to your `server.cfg` file to ensure the resource is loaded when the server starts:
   ```
   ensure FiveMJobCreator
   ```

## Use

1. Start your FiveM server.
2. Use the in-game command `/createjob <name> <description> <salary>` to create a new job. Replace `<name>` with the job name, `<description>` with a brief description of the job, and `<salary>` with the salary amount.
   - Example: `/createjob Mechanic "Fixes vehicles" 5000`
